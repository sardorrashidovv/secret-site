## 📤 Загрузи на GitHub Pages

### Способ 1: Через GitHub Desktop
1. Откройте GitHub Desktop
2. Выберите "Add" → "Add Local Repository"
3. Выберите папку `secret-site`
4. Нажмите "Publish repository"

### Способ 2: Через команду строки
```bash
git add .
git commit -m "Initial commit - Secret dossier site"
git push origin main
```

## ⚙️ Включение GitHub Pages

1. Перейди в **Settings** репозитория
2. Найди раздел **Pages** (слева в меню)
3. В разделе **Source** выбери:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажми **Save**
5. Подожди 1-2 минуты

## 🔧 Как редактировать

### Изменить имя подруги
Открой `script.js` и найди:
```javascript
const CONFIG = {
    friendName: "Умутай",
};
```

### Добавить свои вопросы в викторину
В `script.js` найди `QUIZ_QUESTIONS`:
```javascript
const QUIZ_QUESTIONS = [
    {
        question: "Твой вопрос?",
        options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
        correct: 0  // Индекс правильного (0, 1, 2 или 3)
    },
];
```

### Добавить свои характеристики
В `script.js` найди `CHARACTERISTICS`:
```javascript
const CHARACTERISTICS = [
    "😂 Профессиональный генератор хаоса",
    "💅 Эксперт по красивому существованию",
    // Добавь свои!
];
```

### Изменить цвета
Открой `style.css` и найди `:root`:
```css
:root {
    --primary-color: #ff006e;      /* Розовый */
    --secondary-color: #8338ec;    /* Фиолетовый */
    --accent-color: #3a86ff;       /* Голубой */
}
```
